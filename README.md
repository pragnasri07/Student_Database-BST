# Student Database Management Using Binary Search Tree

A Python project that manages student records using a Binary Search Tree (BST).

## Features

- Add student
- Search student
- Display students
- Update student
- Delete student
- Exit the program

## Technologies Used

- Python
- Binary Search Tree
- Data Structures

## How to Run

Open the project in PyCharm and run:

student_database.py
